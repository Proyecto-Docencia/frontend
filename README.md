# Frontend – Proyecto Docencia

Este repositorio contiene el frontend (Vite + React + TypeScript) del proyecto.

## Clonar

```
git clone https://github.com/Proyecto-Docencia/frontend.git
cd frontend
```

## Requisitos
- Node.js 18+ recomendado
- npm o yarn

## Instalar dependencias

Con npm:
```
npm install
```

Con yarn:
```
yarn install
```

## Desarrollo

```
npm run dev
```
ó
```
yarn dev
```

La app quedará disponible en `http://localhost:5179`.

## Build de producción

```
npm run build
```
ó
```
yarn build
```

## Previsualización del build

```
npm run preview
```
ó
```
yarn preview
```
